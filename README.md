# OMM operon manuscript: analysis resources

Code, data and documentation for analyses used in the manuscript belong here,
with each contribution in a separate top-level folder.

**Current status:** the supplied operon repository has not yet been linked to a
specific published output. This checkout therefore contains provenance and figure
mapping documentation only. It is not yet an executable manuscript reproduction.
Unreported and unconfirmed analysis programs, results, environments and tests have
been excluded from the publication branch.

| Location | Contents |
| --- | --- |
| [Figure-to-code index](docs/figure-code-map.md) | Relevant panels, methods described in the paper, source status and missing files |
| [muench_operon](muench_operon/README.md) | Status of this contribution and a machine-readable figure manifest |
| [Analysis policy](docs/analysis-policy.md) | Rules for including analyses and checking corrections |
| [Provenance](docs/provenance.json) | Paper version, PDF hashes, source repository and recovery locations |

No figure is labeled as generated by code unless that relationship is verified.
The immediate provenance question is the source of Fig. S6C's mutation diagram;
Fig. 4C may share reference annotations. Both relationships remain unconfirmed.

As source code and data are identified, add them under the relevant contribution
folder and update the figure manifest with exact inputs, command and outputs.
Other contributions can be added in separate top-level folders. Manuscript text
and the supplied PDFs remain outside this repository.

## Local recovery

later reference/mapping review. It is excluded from this publication branch.
The original imported history is retained locally on `main`; the clean branch is
`manuscript-only`. Publish only the intended clean branch, not all local branches.
