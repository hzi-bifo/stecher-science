# Codon / operon analysis — Münch contribution

This section covers the fructoselysine/glucoselysine utilization operon in
*Enterococcus faecalis*, including gene organization, sequence variation and
reference annotations.

Part of **Gut microbiota within-host evolution enforces colonization resistance
against enteric infection** by Silva, Woelfel et al.
